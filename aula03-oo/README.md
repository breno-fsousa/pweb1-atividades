# Aula 03: Orientação a Objetos com PHP (Aula A)

## Como rodar

Abra um terminal **dentro desta pasta** (`aula03-oo`). As questões 01 a 07 rodam direto no terminal:

```
php q01-do-array-a-classe/livro.php
```

A questão 08 é uma página web. Suba o servidor nesta mesma pasta e use **outro terminal** para o `curl.exe`:

```
php -S localhost:8000 -d display_errors=1 -d output_buffering=0
```
